# Локальный Docker-запуск

Нужен Docker Desktop или Docker Engine с Compose v2. Из корня репозитория:

```bash
docker compose up --build
```

Откройте <http://127.0.0.1:8501>. Выберите три Parquet из распакованного архива
организаторов и нажмите «Построить граф». Подготовленные `data/` и `out/` не нужны:
`copilot` запускает локальный API загрузки и анализа, `ui` отдаёт React через nginx.
В интерфейсе можно заменить набор и скачать результаты без команд в терминале.
[Формат входа, лимиты и API](uploads.md).

Для фонового запуска добавьте `-d`. Остановка с сохранением данных:

```bash
docker compose down
```

Загруженные файлы, версии CSV и активный снимок сохраняются в именованном volume
`datasets` проекта Compose (`/app/state` в контейнере). Обычные `down` и пересборка
образа его сохраняют. Удаление volume удаляет и эту историю. Не включайте `-v`,
если хотите сохранить анализ. Наборы автоматически не удаляются.

`data/`, `out/`, `.money-graph/`, ключи и git-метаданные исключены из build context.
Поэтому образы можно собирать без датасета. Каталог `out/` на хосте монтируется
только для чтения в API и nginx для совместимости с CLI (при отсутствии Docker
создаст пустую папку). При первом запуске API может импортировать полный набор
из `out/`; сохранённая версия загрузки имеет приоритет на следующих запусках.
Кнопка загрузки позволяет заменить её без перезапуска.

NVIDIA не требуется. При явной настройке `NVIDIA_API_KEY` и `NVIDIA_MODEL` они
передаются только сервису Copilot во время запуска и не включаются в image или
frontend. API не публикуется отдельным портом; `/api/*` проксирует nginx.
HTTP доступен только на loopback. Другой порт UI:

```bash
UI_PORT=8508 docker compose up --build -d
```

## Отдельный CLI/batch для жюри

Распакуйте три файла в `data/`, создайте папку выгрузок и запустите:

```bash
mkdir -p out
docker compose run --build --rm pipeline
```

`pipeline` входит в профиль `batch` и не является обязательным шагом старта UI.
Явный `compose run` запускает его отдельно. Он читает `data/` только для чтения
и пишет `out/nodes_roles.csv`, `clusters.csv`, `top_nodes.csv`, `edge_table.csv`,
`run_report.md` и `run_report.json`. Включён `--check-repro`: второй прогон обязан
дать те же sha256. Этот batch не заменяет активную браузерную версию: для этого
загрузите исходные файлы через UI.

## Проверки

```bash
./scripts/docker-smoke.sh
```

Нужны `curl`, Python 3 со стандартной библиотекой и три Parquet в `data/`
(другую папку можно передать первым аргументом). Скрипт поднимает Docker, загружает
файлы через HTTP, ожидает готовности, проверяет CSV, версию Copilot и локальный
ответ с фактами. Он меняет активный набор и останавливает сервисы после проверки,
сохраняя volume. Для проверки в браузере см. [uploads.md](uploads.md).

В образе используются Python 3.11 и `networkx==3.6.1`. Хеши сравнивайте между
прогонами в одном окружении: последние знаки float могут зависеть от ОС.

## Состав образов

- `pipeline`: `python:3.11-slim`, аналитика, HTTP API и зависимости; работает
  от отдельного пользователя, сохраняет загруженные наборы в writable volume.
- `ui`: nginx и собранный React из отдельного Node build stage.

Runtime не требует внешней сети для загрузки, анализа и локального Copilot.
Первичная сборка требует доступа к Docker registry, PyPI и npm.
Сервис рассчитан на локальное демо одного аналитика. Публичное размещение,
аккаунты и многопользовательская изоляция в этот MVP не входят.
