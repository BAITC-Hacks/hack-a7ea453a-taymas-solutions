# Money Graph UI

React + TypeScript + Vite + Cytoscape.js интерфейс для локальных выгрузок
Python-пайплайна. Браузер читает `../out/nodes_roles.csv`,
`clusters.csv`, `top_nodes.csv` и `edge_table.csv`; для просмотра графа API не
требуется. Панель помощника использует локальный Python API; NVIDIA опциональна.
`gid`, `src` и `dst` читаются как строки, чтобы не потерять
18-значные идентификаторы в JavaScript.

## Первый запуск

Из корня репозитория:

```bash
python -m money_graph --data data --out out
cd frontend
npm ci
npm run dev
```

Откройте URL, который напечатает Vite. Во время разработки Vite проксирует
`/out/*` из соседней папки `out/`. Если данных ещё нет, нажмите «Открыть
демо-набор» на экране ошибки, чтобы увидеть небольшой синтетический fixture.

## Проверки

```bash
npm test
npm run build
npm run preview
```

Production build включает доступные на момент сборки файлы `out/*.csv` в
`dist/out/`. Папка `out/` с обезличенными данными остаётся локальной и не
коммитится в Git.

## Помощник по расследованию

В отдельном терминале из корня проекта запустите `python -m agent_orchestrator.server --out out`.
Vite и preview проксируют `/api/copilot` в этот процесс. Откройте вкладку «AI Copilot»
рядом с графом: три подсказки, контекст до пяти gid, проверяемые факты и следующие шаги.
Ключ для локальных ответов не нужен. Docker Compose запускает сервис автоматически.

[Контракт, проверки и демо на 90 секунд](../docs/copilot_panel.md).

## Рабочее пространство Taymas

- Экран открывается на первом клиенте из `top_nodes.csv` и его непосредственных
  соседях. Справа сразу доступен реальный Copilot. «Соседи» возвращает обзор сети; «Сбросить фильтры» также снимает выбор.
- Точный GID открывает клиента и входящих/исходящих соседей независимо от ранее
  выбранных фильтров. Неполный GID фильтрует по фрагменту. Например, `123` не является
  точным GID, но в реальной выгрузке есть четыре совпадения по фрагменту.
- Поиск полного GID, строка очереди, контрагент в карточке и ссылка Copilot
  открывают карточку и полное непосредственное окружение клиента. Все наблюдаемые
  входящие и исходящие связи сохраняются, даже если окружение превышает лимит.
  Фильтры остаются выбранными: над графом указано число узлов вне фильтров и
  сверх лимита. «Снять временное окружение» возвращает вид по этим фильтрам.
  Для изолированного seed показывается один узел без рёбер.
- Цвет графа переключается между ролью и кластером. Семантика ролей сохранена в
  легенде. Кольцо обозначает seed; стрелки направлены к получателю. В режиме «Потоки»
  плательщики слева, получатели справа; двусторонний контрагент располагается
  по большему наблюдаемому потоку. Стрелки сохраняют оба направления. Отдельные
  узлы из ответа без прямой связи размещаются снизу. Верхние суммы относятся
  только к связям текущего вида; полные суммы есть в карточке. Для окружения до
  65 узлов доступны «Потоки / Сеть», для больших видов — концентрическая сеть.
  Положение узла не является дополнительной оценкой риска.
- Общий обзор ограничен 30–500 узлами; явное открытие окружения и факты Copilot
  могут превышать этот лимит. Все 30 строк очереди доступны по «Все 30 клиентов»;
  все контрагенты — через раскрытие списков. Evidence и основания не обрезаются.
- «Режим фокуса» разворачивает граф и панели на рабочую область без потери
  фильтров, вопроса и ответа. «Вернуть обзор» возвращает сводку и очередь.
- Тема — `src/styles/tokens.css`, стили разделены на layout/network/inspector.
  `ROLE_COLORS` ссылается на CSS-переменные; Cytoscape получает вычисленные цвета.
  Шрифты системные, иконки встроены в SVG. Новых зависимостей нет. AI-провайдер включается только явно в панели Copilot.

### Интеграция PAN-48

Реальный `CopilotPanel` встроен одной строкой через компонент-обёртку:

```tsx
<CopilotSlot><CopilotPanel data={data} selectedId={selectedId} onNavigate={focusNode} onAnswer={receiveAnswer} /></CopilotSlot>
```

Панель остаётся смонтированной при переключении вкладок и выборе клиента.
`answerHighlights` и `includeEvidence` добавляют подтверждённые узлы вне
фильтров/лимита, подсвечивают цитируемые рёбра. Переход из ответа сохраняет
фильтры и открывает полное окружение выбранного клиента; повторный переход
снова центрирует камеру. Получение ответа само по себе не выполняет переход.
Снятие подсветки Copilot и снятие открытого окружения — отдельные действия.
Внешняя адаптация темы — `src/styles/copilot-integration.css`; исходники и
логика `src/copilot/`, API, зависимости и конфигурация Vite не изменены. Включён и оформлен
локальный план недостающих данных PAN-54 из актуального main.

Регрессии навигации: `npm test -- tests/app.test.tsx tests/investigation.test.ts`.
Для browser smoke сначала создайте `out/` пайплайном и запустите Vite, затем
в другом терминале из `frontend/` выполните
`COPILOT_UI_URL=http://127.0.0.1:5173 npm run test:e2e -- navigation.spec.ts`.
Тест берёт произвольный связанный GID вне топа и изолированный seed из локальных
CSV, проверяет переход к соседу, сохранение фильтров и отсутствующий GID.
Для этого сценария API и NVIDIA не нужны: HTTP-ответы CSV фиксируются на время теста.

PR открывается после локального просмотра пользователем. Перед PR — fetch,
rebase на актуальный main, повторные проверки. Самостоятельно не мержить.

### Визуальные ориентиры

В режиме «Кластеры» над графом показана легенда «цвет → cluster_id» только для
узлов текущего вида; длинная легенда прокручивается с клавиатуры и мышью.
Стрелки и кольцо seed сохраняют свой смысл. Счётчик очереди показывает число
видимых строк и общее число; «Все N клиентов» раскрывает весь top-list в порядке CSV.
В карточке «Показать все N связей» отдельно раскрывает входящие и исходящие связи,
а агрегаты всегда учитывают полный список.

Проверки PAN-61: `npm test -- tests/complete-display.test.tsx` и
`COPILOT_UI_URL=http://127.0.0.1:5173 npm run test:e2e -- complete-display.spec.ts`.
Для browser smoke нужны локальные CSV в `out/` и работающий Vite. Тест проверяет
реальные цвета canvas, стрелки, seed, полные списки и длинные GID при ширине
1440 и 390 px. API и NVIDIA для этого сценария не нужны.

- [Linkurious: Using Copilot](https://doc.linkurious.com/user-manual/latest/using-copilot/):

Внешние изображения и ресурсы в продукт не включаются. Вся графика строится
из локальных CSV, SVG и CSS; шрифты системные.
